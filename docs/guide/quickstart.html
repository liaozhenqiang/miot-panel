快速开始

下载、安装、设置 PIN 和登录小米账号，三步把面板跑起来。

米家面板支持 Windows、Linux（含玩客云/树莓派等 armv7 设备）、Docker / NAS，以及 PWA 和 Android 客户端。第一次使用只需要完成三件事：安装、设置 PIN、登录小米账号。

下载

所有安装包都在 GitHub Releases。当前版本 v0.7.32，按平台选择：

平台推荐安装包说明
Windowsmiot-panel-v0.7.32-windows-installer.exe一次安装 x64 / x86 / ARM64 运行时，自动选择架构
Windows 便携...-windows-x64-portable.zip 等解压即用，适合不想安装
Linux x86_64...-linux-amd64-installer.run自解压安装并注册 systemd 服务
Linux ARM64...-linux-arm64-installer.run树莓派 4/5、ARM 迷你主机等
Linux ARMv7...-linux-armv7-installer.run玩客云、树莓派 2/3、老电视盒子
Linux 完整包...-linux-<arch>-bundle-installer.run自带摄像头组件，装完即用，不必再联网下载组件
Docker / NAS...-docker-multiarch.tar / ...-docker-installer.runamd64 / arm64 / armv7 多架构镜像
Androidmiot-panel-android-1.0.5.apk原生 PIN 解锁 + WebView 面板，支持自动发现
安装包较多时以 Release 页面说明为准；升级一般会保留数据、PIN 和登录态。

Windows 安装

  1. 下载并运行 miot-panel-v0.7.32-windows-installer.exe。
  2. 安装器会按真实 CPU 选择 x64 / x86 / ARM64 运行时；安装完成后启动面板并加入开机自启。
  3. 浏览器打开 http://127.0.0.1:8080（或安装器提示的端口），设置管理员 PIN。
  4. 用小米账号登录，等待设备列表同步。
Windows 首次连接摄像头时如果弹防火墙提示，请允许 go2rtc.exe 和 ffmpeg.exe 的局域网访问。

Linux / 玩客云安装

以 amd64 为例；armv7 / arm64 换成对应文件名：

chmod +x miot-panel-v0.7.32-linux-amd64-installer.run
sudo ./miot-panel-v0.7.32-linux-amd64-installer.run

安装器会安装到系统目录并注册 miot-cloud 服务，默认端口通常为 80。安装完成后访问：

http://<设备IP>/

玩客云等 armv7 设备请使用 linux-armv7 包，包内带预编译依赖轮子，不需要现场编译。

Docker / NAS 安装

Release 提供多架构 OCI 镜像 tar 和 Docker 安装器。以 OCI tar 为例：

docker load -i miot-panel-v0.7.32-docker-multiarch.tar
docker run -d --name miot-panel \
  -p 8080:80 -v miot_data:/data \
  --restart unless-stopped liaozhenqiang/miot-panel:0.7.32

也可以使用 docker-installer.run 或包里的 docker-compose.yml。数据卷必须保留，升级时不要删除。

首次设置

  1. 打开面板地址，设置 管理员 PIN（4–20 位）。PIN 保护后台和 go2rtc 代理。
  2. 登录小米账号：支持账号密码或扫码；登录态会加密保存在本机。
  3. 进入 /admin 检查设备、排版、天气和家庭过滤；需要摄像头/音乐时再安装对应组件。
只想当普通网页用也可以：电脑或手机直接打开面板地址，无需安装客户端。

升级与备份

Windows / Linux / Docker 都可以在后台「系统更新」里检查新版本；也可以下载新安装包覆盖安装。升级前建议在后台「配置迁移」导出一份带口令的备份，设备、登录态和设置都会保留。
