后台与安全

后台分区、PIN、家庭过滤、局域网、更新、备份迁移和安全建议。

后台地址是 /admin，使用安装时设置的管理员 PIN 登录。后台采用顶部分区切换，不需要一直向下滚动。

概览与分区

  • 概览：登录态、设备数量、摄像头/音乐组件、更新和最近的告警。
  • 设备：设备显示/隐藏、改名、家庭过滤和天气。
  • 外观：主题、排版、光标、组件位置和自定义页面。
  • 摄像头：本机/远程 go2rtc、摄像头组件状态、远程摄像头服务和云台转发。
  • 音乐与音箱：音乐中心连接、账号绑定、音箱分组、AI 和 TTS。
  • 安全与维护：修改 PIN、锁定设备、恢复默认和退出小米账号。
  • 自检与迁移：一键诊断、配置迁移包、更新与日志。

PIN 与设备访问

管理员 PIN 保护后台和 go2rtc 代理；设备访问使用签名 Cookie，改 PIN 或首次设置会轮换密钥，旧 Cookie 自动失效。登录、验证码和控制接口都有限流，不对公网开放。

面板默认监听局域网 HTTP，请务必设置 PIN，不要把端口直接映射到公网。远程访问建议使用 VPN / 内网穿透并额外加认证。

家庭过滤与局域网

如果账号下有多个家庭，可在后台用公网 IP 前缀或局域网 IP 前缀筛选当前家庭；面板只会显示匹配的设备。多网卡 / VPN 环境下如果面板与摄像头不在同一网段，可在后台补一个远程 go2rtc 地址，或在「局域网地址」里选择正确网卡。

主题与排版

主题会持久化并对摄像头页生效；排版包括「每页几列 × 几行」和拖拽顺序，手机/平板/墙面板共用一套布局。恢复默认只会影响排版或外观，不会动设备数据。

更新、备份与迁移

  • 「系统更新」支持检查 GitHub Release 并热更新程序文件；更新时代板会短暂离线。
  • 「配置迁移」可导出带口令的加密备份，包含登录态、主题排版、设备改名/隐藏、摄像头和音乐中心凭据；换设备时导入后自动校验。
  • 「服务日志」可以查看/清理面板日志；「诊断」会汇总账号、设备、摄像头、音乐中心和组件状态，IP 自动打码。
升级前先导出备份；不要在面板目录里手工删除 micloud_auth.json、cloud_config.json 或迁移包。
