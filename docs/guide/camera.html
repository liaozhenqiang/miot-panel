摄像头

摄像头组件安装、播放、清晰度、云台和跨网段远程 go2rtc。

摄像头是可选功能。面板通过本机 go2rtc + ffmpeg 播放摄像头画面，并可在后台管理远程 go2rtc 地址和云台。摄像头不要求面板与摄像头在同一网段，跨网段时填写远程 go2rtc 即可。

安装摄像头组件

  1. 打开面板左侧「摄像头」，首次会提示组件未就绪。
  2. 点安装组件，面板会自动下载并校验 go2rtc、ffmpeg，然后启动。
  3. 组件就绪后打开摄像头页，选择摄像头即可播放。
Windows 防火墙可能会拦截摄像头程序的 UDP；首次播放失败时请在后台或摄像头页允许相关程序，或安装器提示的防火墙规则。

摄像头页

  • 左侧是摄像头列表，右侧播放；支持主题同步、全屏和移动端单列。
  • 支持的摄像头可在播放器右下角使用方向盘控制云台（按住连续转动，松手停止；具体以设备和平台实际能力为准）。
  • 右上角可在流畅 / 高清之间切换，切换的是面板转码档位，不需要改摄像头设置。
  • 左上角「声音」按钮打开麦克风监听，选择会被记住；浏览器要求第一次必须由你点一下才允许出声，所以默认仍是静音。
  • H.264 摄像头直接播放原始流，不再多转一道；HEVC 才走本机转码。点开时先显示上一帧画面，真实画面接上后自动切换。
  • 多路同时播放会占用 CPU；性能较弱的设备建议只播放需要的画面。

跨网段 / 远程 go2rtc

如果面板和摄像头不在同一网段，或希望复用另一台设备上的 go2rtc：

  1. 在提供 go2rtc 的设备上打开后台，允许其他面板使用本机 go2rtc，并记下 go2rtc 地址。
  2. 在面板后台「摄像头 → 远程摄像头服务」填写该地址，例如 http://<设备IP>:1984，保存并检测。
  3. 摄像头页会从远程 go2rtc 播放；远程设备需自行限制来源并保证局域网可信。

云台控制也可以在后台的「云台转发」里填写对方面板地址和共享令牌；视频始终走上面的远程 go2rtc，云台转发只负责方向键。

常见检查

  • 组件未就绪：到摄像头页重新安装/重启组件，确认 1984、8554 端口没有其他程序占用。
  • 能打开但黑屏：检查摄像头是否在线、面板与远程 go2rtc 是否能互通，以及 ffmpeg 是否可用。
  • 跨网段提示：填写远程 go2rtc，或把面板放到与摄像头同网段的设备上。
  • 摄像头页打不开：确认 PIN 已设置；面板的 go2rtc 代理需要 PIN。
  • 点了「声音」还是没声：确认摄像头本身开启了麦克风；监听音量小的机型需要摄像头端拾音，面板不会替设备打开录音。
