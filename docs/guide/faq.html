常见问题

打不开、PIN、设备、摄像头、音乐、Docker 和 armv7 的排查。

打不开面板

确认服务/容器在运行，端口没有被其他程序占用；Windows 查看托盘或安装目录，Linux 运行 systemctl status miot-cloud，Docker 查看 docker logs。默认端口：Windows 8080，Linux/Docker 常见 80。

忘记 PIN

PIN 只保存在本机配置中，无法从云端找回。可以在设备上删除/重置配置重新进入首次向导；如果只是要换 PIN，且仍能登录后台，直接到「安全与维护」修改即可。删除配置会同时失去本机登录态，请先导出备份。

设备显示不完整

检查小米账号是否登录、家庭过滤是否只匹配了另一个家庭、设备是否在线。传感器没有云端数据、纯 BLE 设备或账号下不匹配的设备不会显示。

摄像头黑屏 / 组件未就绪

先到摄像头页安装或重启组件，确认 1984、8554 端口未被占用，再检查防火墙。跨网段时填写远程 go2rtc；仍然黑屏时查看摄像头是否在线、编码是否被面板支持。

音乐中心连不上

确认 Songloft / go-music-dl 正在运行、地址和端口可从面板访问、管理员凭据正确；Docker 容器连接宿主机上的音乐中心时不要填 127.0.0.1，应填宿主机的局域网 IP。

Windows 弹防火墙 / 黑窗

新版已统一隐藏控制台窗口；摄像头首次连接时允许 go2rtc.exe、ffmpeg.exe 的局域网访问。若仍被拦截，到 Windows 防火墙放行对应程序或重新运行安装器的防火墙配置。

Docker 升级后数据没了

升级容器时没有保留数据卷。面板数据在容器内 /data，请挂载固定卷/目录；升级前也可以从后台导出迁移包。

armv7 性能

玩客云等 armv7 设备使用包内的预编译轮子，不需要现场编译。摄像头转码和多路播放会占用 CPU，建议优先使用流畅档位并减少同时播放路数。

隐私

面板只在你的设备上保存小米登录态、PIN 哈希、设备缓存和配置；不会把账号、设备 Token、摄像头画面或 AI Key 上传到第三方。导出的迁移包包含敏感凭据，请妥善保存。
