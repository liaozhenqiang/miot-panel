④ 大模型 / 自定义人设 / TTS
语音指令理解
内置主流 OpenAI 兼容服务商；切换后会改接口地址和默认模型，Key 需换成对应服务商的。
用于理解“把客厅空调调到 26 度”“播放周杰伦”“音量调到 30”等自然语言。默认值是通义 DashScope，可改成 DeepSeek（https://api.deepseek.com/v1）、OpenAI、Moonshot 等任意 OpenAI 兼容地址。
AI 对话人设（回答由小爱原生 TTS 播报）
独立对话连接使用这里的地址、模型和 Key。
如果服务商返回 401 invalid_api_key，说明“Key 不是当前接口地址所属服务商的”，或 Key 已失效/复制不全；先选对服务商再重新填 Key。TTS 默认使用小爱原生语音；插件不提供第三方音色替换。
小爱原生回答先由小米云端生成，插件通过云端轮询发现提问后才会打断，通常有 1–2 秒延迟；短句可能仍会听到原生回答。后台已把轮询调到 1 秒以减少重叠，但无法通过小米云 API 完全消除；要彻底避免需替换原生语音助手（如自定义固件）或改用面板/手机麦克风提问。
